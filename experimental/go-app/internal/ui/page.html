返回格式SSE / JSON

stream:true 返回 SSE；false 或省略 stream 等有效终端才返回最终 JSON，转换失败返回脱敏 502。

上游仍为单次 SSE 请求，不代表真实上游非流式已验证。不自动回退重发。

允许工具集合auto / required

allowed_tools 支持已声明 function / custom 的非空集合，namespace 精确匹配、裸名必须唯一；排除工具返回即拒绝。

历史工具结果仍保留。转换只发送本轮可调用声明，不承诺原生缓存优化；工具由客户端执行。

输出上限明确未完成

max_output_tokens 支持整数 1–1048576；达到上游输出上限时明确返回 incomplete（不是 completed），不保存为可续接历史；畸形半截工具参数仍拒绝。

供应商更低的上限可能拒绝请求，不回退重发。

成功历史仅本进程

previous_response_id 默认支持转换路径同模型的成功历史：64 条 / 总 8 MiB / 单条 1 MiB / 30 分钟。

Stop 或重新配置即清空；store:false 不保存新响应。未知或过期历史拒绝，不跨设备共享。

跨转换模型需每请求显式 X-MOMO-History:replay-v1，回放完整 canonical 历史；目标工具和媒体策略需重声明。源 anchor 不消耗；不转换原生 opaque / 签名状态，不保证模型行为等价。

本地 checkpoint有损 · 手动回放

保留全部指令 / 用户、完整工具回合和最新助手文本；较早的普通助手文本才可换成明确有损标记，不调用模型。

返回 output 需客户端手动重放；cmp_ 不是续聊 anchor。不是语义摘要，也不承诺旧任务完成。

DSML 工具文本默认关闭

仅转换到 Chat 的 Responses 请求可显式使用 X-MOMO-Tool-Text:dsml-v1。模型标签文本会成为已声明工具的调用提案；不按模型自动启用，不继承历史。

保留 namespace 与原始字符串；只有 string=false 参数才解析 JSON。保留标签不能嵌在参数中，畸形或截断时拒绝，不回退重发；客户端仍负责工具审批和沙箱。

详细模型规则与不支持的能力

普通函数 strict 校验

function 的 strict:true 不需要启用工具搜索，也不默认禁止并行调用。支持有界 nullable type 数组；嵌套对象必须要求全部字段并拒绝额外字段。Chat 保留显式 strict bool，Claude/Gemini 仅做本地校验，不捏造协议字段。strict:false 或省略不强加 schema 校验；未知 schema 关键词仍拒绝。历史和生成参数都检查，失败中止、不重试、不保存成功历史；不是上游约束生成或客户端执行回滚保证。

部分路由，不是完整兼容

只有明确启用后，Responses 入口对普通模型走 Chat 转换；mimo-* / *-sol / *-luna / *-responses 原样走 Responses。claude-* 走 Messages 文本/工具与有界 thinking/签名子集：公开摘要单独输出、加密块不显示为文本，签名与顺序仅限原模型回放；显式 momo_claude_thinking 支持 adaptive/manual/disabled 与 adaptive effort，不含 beta/输出媒体/完整原生流，gemini-* 走文本/工具/用户图片与 PDF 子集；公开 thought 摘要单独输出，文本与工具签名仅限原模型回放；显式 momo_gemini_thinking 支持原生四级 level / budget / includeThoughts，与 max tokens 合并、仅本次请求；不猜模型能力或静默降低 effort（不含签名-only 分片/输出媒体/完整签名协议）；Muse 转换不在计划内，实验选路仍明确拒绝。

失败时明确拒绝

exec/apply_patch 支持纯文本 custom 输入，原文保留、由客户端执行；转换不支持 grammar 约束，返回 unsupported_tool_format，不猜 shell 或改写 JS。工具搜索需请求显式启用 momo_tool_loading:client-search 与 parallel_tool_calls:false，仅支持客户端搜索、按顺序加载定义；不是原生延迟加载，不执行 MCP/工具。strict 仅做有界本地校验，不保证上游约束生成。用户 input_image 支持 inline PNG/JPEG/静态 GIF/WebP 与委托上游的 HTTPS 引用，保留文字/图片顺序及同模型历史。总请求/历史仍限 1 MiB、最多 32 张；仅头部/framing 校验，不证明图像内容或模型能力。本机不抓取 URL，不验证 DNS/重定向；Gemini URL 必须显式 mime_type，Claude/Gemini 不支持 low/high detail。配对工具图片：Claude 嵌套结果；Gemini3 inline 结果保留调用归属；已支持的文本/工具签名必须原样保留，不跨模型转换。Chat / 旧 Gemini 或 URL 需每请求显式 momo_tool_images:user-projection；先配对全部并行结果，再按原图文顺序投影成 user，不是原生角色/信任等价或注入防护，不默认回退。PDF input_file 支持 inline canonical Base64；Claude / Gemini 还支持显式 application/pdf 的 HTTPS 引用，Chat 仅 inline。Claude / Gemini 另支持 inline UTF-8 text/plain、text/markdown、text/csv：原样保留 BOM / 换行 / 字节，不渲染文档；Claude 原生文本文档，Gemini text/plain inlineData。Chat 非 PDF 明确拒绝，不偷偷降为 user 文本。非空合法 UTF-8，控制字符只允许 tab / CR / LF；不支持远端文本 URL。最多 16 个 PDF / 文本文件、32 张图共享 1 MiB decoded 预算，JSON / 历史也限 1 MiB。仅 PDF 头部 / EOF framing，不证明结构或安全；不读取、上传或提取。配对 PDF：Claude 嵌套结果；Chat / 所有 Gemini 需每请求 momo_tool_files:user-projection，混合图片还需图片策略。保留原顺序、调用归属和完整 PDF 回合及解读；策略不继承。显式内存附件：注册一个 inline 图片 / PDF / UTF-8 文本文件，用 X-MOMO-Attachments:inline 与 momo_attachment 引用；最多 64 条 / 8 MiB / 绝对 30 分钟，停止清空，不读取磁盘或云上传。删除附件不撤回已存历史：续聊保存独立 inline 快照，含已删除引用的完整重放拒绝；无附件选择器或自动客户端接入。file_id、其他不支持的非 PDF 文件、其他媒体、opaque 状态与未知参数在转换路径明确拒绝。独立 compact 可显式请求 X-MOMO-Compact:native 尝试原生 Responses 上游，保留密文字节但不验证语义、不回退。无请求头时默认 501；实验本地 checkpoint 保留完整工具/图片回合及解读、不含加密 envelope，支持已完成的工具搜索 / 动态追加定义完整回合；待完成工具或搜索拒绝，需重声明工具和策略再手动回放。不自动触发或转换供应商状态。
