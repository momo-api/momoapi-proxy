返回格式SSE / JSON

stream:true 返回 SSE；false 或省略 stream 等有效终端才返回最终 JSON，转换失败返回脱敏 502。

上游仍为单次 SSE 请求，不代表真实上游非流式已验证。不自动回退重发。

允许工具集合auto / required

allowed_tools 支持已声明 function / custom 的非空集合，namespace 精确匹配、裸名必须唯一；排除工具返回即拒绝。

历史工具结果仍保留。转换只发送本轮可调用声明，不承诺原生缓存优化；工具由客户端执行。

输出上限明确未完成

max_output_tokens 支持整数 1–1048576；达到上游输出上限时明确返回 incomplete（不是 completed），不保存为可续接历史；畸形半截工具参数仍拒绝。

供应商更低的上限可能拒绝请求，不回退重发。

成功历史仅本进程

previous_response_id 支持转换路径同模型的成功历史：64 条 / 总 8 MiB / 单条 1 MiB / 30 分钟。

Stop 或重新配置即清空；store:false 不保存新响应。未知或过期历史拒绝，不跨设备共享。

本地 checkpoint有损 · 手动回放

保留全部指令 / 用户、完整工具回合和最新助手文本；较早的普通助手文本才可换成明确有损标记，不调用模型。

返回 output 需客户端手动重放；cmp_ 不是续聊 anchor。不是语义摘要，也不承诺旧任务完成。

详细模型规则与不支持的能力

部分路由，不是完整兼容

只有明确启用后，Responses 入口对普通模型走 Chat 转换；mimo-* / *-sol / *-luna / *-responses 原样走 Responses。claude-* 走 Messages 文本/工具子集（不含 thinking/签名），gemini-* 走文本/工具子集（不含 thinking/签名/媒体）；Muse 转换不在计划内，实验选路仍明确拒绝。

失败时明确拒绝

exec/apply_patch 支持纯文本 custom 输入，原文保留、由客户端执行；转换不支持 grammar 约束，返回 unsupported_tool_format，不猜 shell 或改写 JS。工具搜索需请求显式启用 momo_tool_loading:client-search 与 parallel_tool_calls:false，仅支持客户端搜索、按顺序加载定义；不是原生延迟加载，不执行 MCP/工具。strict 仅做有界本地校验，不保证上游约束生成。转换媒体、opaque 状态与未知参数明确拒绝。独立 compact 可显式请求 X-MOMO-Compact:native 尝试原生 Responses 上游，保留密文字节但不验证语义、不回退。无请求头时默认 501；实验本地 checkpoint 仅文本工具历史、不含加密 envelope，不支持工具搜索历史或待完成工具。不自动触发或转换供应商状态。

系统凭据

隐私与生命周期

本地优先

本地接口需要认证，拒绝浏览器 Origin / Sec-Fetch 请求；不开放局域网监听。配置默认只在内存中，不自动导入其他软件账号。

Windows / macOS 关闭窗口隐藏至托盘；Linux 关闭窗口退出。退出停止本进程代理。多次启动是独立实例，没有后台守护或单实例协调器。

输入 Key 会经过本地 WebView；清空不等于安全内存擦除。复制配置可能被其他应用或剪贴板历史读取。
