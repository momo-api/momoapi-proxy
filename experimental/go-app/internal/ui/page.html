系统凭据

明确授权

Windows Credential Manager / macOS Keychain / Linux Secret Service。启动不自动读取；保存后，下次打开请明确读取并启动。

删除保存记录不会清除本次内存配置，也不会停止代理。取消保存勾选不会删除旧记录。卸载默认保留凭据和 WebView 数据。

隐私与生命周期

本地优先

本地接口需要认证，拒绝浏览器 Origin / Sec-Fetch 请求；不开放局域网监听。配置默认只在内存中，不自动导入其他软件账号。

Windows / macOS 关闭窗口隐藏至托盘；Linux 关闭窗口退出。退出停止本进程代理。多次启动是独立实例，没有后台守护或单实例协调器。

输入 Key 会经过本地 WebView；清空不等于安全内存擦除。复制配置可能被其他应用或剪贴板历史读取。
